```text
                           licence texts included)

                           "Neago <neagoe_mb_89@yahoo.com>" (6 commits)
generated_artifacts      = review sheets (tests/corpus/code_aster_start/review/*.yaml, generated by cgs audit);
                           docs/bench/fortran_parsers.md (benchmark report); no build output tracked (dist/ ignored)
recommendation           = KEEP_HISTORY
```

Details:

- **Secrets.** Every revision was searched for private keys, cloud/API tokens, GitHub tokens, OAuth client secrets,
  passwords and API keys: no match.
- **Analysed code in history.** No Code_Aster source file was ever committed (`corpus_src/` is ignored); all Fortran,
  C, C++ and Python files in history are the project's own fixtures.
- **License-sensitive files.** The two review sheets contain 1,350 single-line excerpts of Code_Aster source code
  (GPL-3.0) with their locations, for manual review. Short excerpts for verification are probably acceptable, but this
  is a **legal-review item**; the conservative alternative is to stop tracking the sheets (regenerate them locally with
  `cgs audit sample` / `recall-sample`) — to be decided by the owner, not changed here.
- **Contributors.** Apparently a single author under two e-mail addresses (to be confirmed by the owner): if so,
  copyright provenance is clear and no CLA is needed for past commits. A `.mailmap` could unify the identities.
- **History value.** The history documents the lot-by-lot construction and the validation work; nothing in it requires
  rewriting.
